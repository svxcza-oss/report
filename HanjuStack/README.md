# 한 주 쌓기 (맥 앱 + 위젯)

할 일을 시간 길이만큼의 블록으로 만들어 일주일 판에 쌓는 앱이에요.
화면은 `Resources/index.html`(웹 페이지), 저장과 위젯은 Swift가 맡아요.

## 다운로드

**[⬇︎ HanjuStack.zip](https://github.com/svxcza-oss/report/releases/latest/download/HanjuStack.zip)** — main이 바뀔 때마다 GitHub Actions가 자동으로 새로 빌드해요 (`.github/workflows/hanju-release.yml`).

1. 받아서 풀고 `HanjuStack`을 응용 프로그램 폴더로 옮겨요.
2. 처음 열 때 "확인되지 않은 개발자"로 막히면: 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**
   (또는 `xattr -dr com.apple.quarantine /Applications/HanjuStack.app`)
3. 바탕화면 우클릭 → 위젯 편집 → "한 주 쌓기"

## 내 맥에서 직접 빌드 (개발자 계정 필요 없음)

Xcode와 XcodeGen만 있으면 돼요 (`sudo xcode-select -s /Applications/Xcode.app`, `brew install xcodegen`).

```sh
pkill -x HanjuStack
./build-local.sh
rm -rf /Applications/HanjuStack.app && cp -R build/local/Release/HanjuStack.app /Applications/
open /Applications/HanjuStack.app
```

예전 개인용 설치와 같은 저장 파일을 써서 쓰던 계획이 그대로 이어져요. 앱은 샌드박스 없이 위젯 폴더 안의 파일을 직접 같이 써요
(`project.local.yml`, `Config/Local.xcconfig`). 이 방식은 내 맥 전용이고, 앱스토어에는 아래 서명 빌드를 써요.

## 빌드·App Store 준비

전체 Xcode와 XcodeGen을 설치하고 `Config/Signing.xcconfig`에 본인의 Apple Developer Team ID와 고유 Bundle ID를 설정하세요. 앱과 위젯에 같은 App Group을 연결해야 합니다.

```sh
./scripts/check.sh      # 계정 없이 실행 가능한 소스/저장 검사
./build.sh              # 개발자 서명 빌드
./scripts/archive.sh    # App Store용 Universal archive, 자동 업로드 없음
```

계정 생성, 기존 데이터 가져오기와 제출 전 확인은 [APP_STORE.md](APP_STORE.md)에 정리했습니다. 아직 개발자 계정이 없으면 설정의 예시 ID를 실제 ID로 바꾼 다음 서명·실행 검증을 마쳐야 합니다.

## 글꼴

앱·위젯 모두 **나눔고딕**을 앱 안에 넣어서 써요 (SIL Open Font License, `Resources/Fonts/OFL-NanumGothic.txt`). 따로 설치할 필요 없고, 앱스토어 판매에도 쓸 수 있어요.

## 레서

- 앱 안: 화면 아래쪽을 돌아다니다가 가끔 멈춰서 포인터를 쳐다봐요. **누르면 대화창**이 열려요 (레서 바꾸기는 대화창 위쪽 버튼).
- 바탕화면: 화면 맨 아래(Dock 위)를 돌아다녀요. 상단바 레서 우클릭 → "바탕화면 레서"에서 바탕화면에서 / 모든 창 위에서 / 끄기를 골라요. 클릭을 막지 않아요.
- 켜고 끄기는 하나로 묶여 있어요: 앱 아래 **레서 숨기기/보이기**를 누르면 바탕화면 레서도 같이 숨거나 나오고, 상단바에서 "끄기"를 고르면 앱 안 레서도 같이 숨어요. 바탕화면/모든 창 위 위치는 끈 동안에도 기억해요.
- 절전 모드는 어두운 화면이에요. 레서는 그대로 움직이고, 위젯도 같은 모드로 바뀌어요.

## 오늘·이번 주 할 일

시간을 정하지 않는 체크리스트예요. 판 아래에 두 목록이 있어요.

- **오늘 할 일**: 매일 하는 것 (물 2L, 스트레칭…). 날짜가 바뀌면 체크가 새로 시작돼요.
- **이번 주 할 일**: 이번 주 안에 할 것 (장보기, 빨래…). 월요일마다 체크가 새로 시작돼요.
- 입력칸에 쓰고 Enter로 추가, 글자를 눌러서 고치기(비우면 삭제), ✕로 지우기. **체크하면 아래로** 내려가요.
- 위젯 **오늘·이번 주 할 일**: 네모를 누르면 앱을 열지 않고 바로 체크돼요. **+** 를 누르면 앱이 열리면서 그 목록 입력칸에 바로 커서가 가요 (위젯 안에서는 글자를 입력할 수 없어서예요).

## 레서와 대화

레서를 누르면 말풍선 대화창이 열려요. "오늘 뭐 남았어?", "내일 오후 3시에 운동 1시간 넣어줘", "PCCP 완료로 해줘"처럼 말하면 레서가 실제로 블록을 보고·쌓고·체크·옮겨요.

대답을 만드는 AI는 대화창 ⚙︎에서 골라요. **자동**이면 아래 순서로 써요.

1. **내 API 키** — Claude 또는 OpenAI 키를 넣으면 그 키로 대화해요. 키는 이 기기의 키체인에만 저장되고, 저장 파일·위젯·GitHub에는 들어가지 않아요. 요금은 키 주인에게 나가요. 모델은 비우면 기본값(`claude-haiku-5-5`, `gpt-5-mini`)이고 직접 바꿀 수 있어요.
2. **Apple 기기 안 모델** — macOS 26 / iOS 26 이상, Apple Intelligence가 켜진 기기(M1 이상 맥, 최신 아이폰)에서 무료·오프라인으로 대화해요.
3. **대본 레서** — 둘 다 안 되면 오늘 계획을 보고 정해진 말로 대답해요 (인텔 맥, 브라우저).

**계획 코치**: "내 계획 분석해줘", "요즘 어때?", "다음 주 계획 같이 세워줘"라고 하면 최근 4주 기록으로 일마다 몇 번·몇 시간 했는지, 요일·시간대별 분포, 완료율, 너무 몰린 날, 자주 못 끝내는 일을 보고 조언해요. 기간 계획을 말하면 블록 목록을 먼저 제안하고, 좋다고 하면 쌓아요.

어느 AI든 같은 도구(`list_blocks`, `add_block`, `set_done`, `move_block`, `list_todos`, `add_todo`, `check_todo`, `plan_stats`)로 계획을 다뤄요. 도구는 페이지의 `window.hanjuTool`이 실행해요 (`AppShared/LesserChat.swift`, `AppShared/ChatBridge.swift`).

## 아이폰·아이패드

`HanjuStackiOS` 타깃이 같은 화면·저장·위젯·레서 채팅을 써요. 번들 ID가 맥과 같아서 앱스토어에서 한 앱(맥 + iOS)으로 묶을 수 있어요.

- 내 아이폰에서 실행: `xcodegen generate` → `open HanjuStack.xcodeproj` → 위쪽에서 **HanjuStackiOS** 와 연결한 아이폰을 고르고 ▶︎ (처음엔 아이폰 설정 → 개인정보 보호 및 보안 → **개발자 모드** 켜기)
- 앱스토어/TestFlight: `./scripts/archive-ios.sh` → Organizer에서 Validate → Distribute
- **잠금화면 위젯**: 잠금화면 사용자화 → 위젯에서 "한 주 쌓기 잠금화면". 동그라미는 오늘 완료 개수, 직사각형은 지금/다음 블록과 남은 할 일, 시계 옆 한 줄은 다음 블록.
- **실시간 현황**: 블록 시간이 되면 잠금화면 아래와 다이내믹 아일랜드에 레서와 남은 시간 카운트다운이 떠요. 3시간 안에 시작하는 다음 블록도 미리 띄워요. **완료** 버튼을 누르면 앱을 열지 않고 완료돼요. (앱을 연 상태에서 시작돼요. 설정 → 한 주 쌓기 → 실시간 현황에서 끌 수 있어요.)
- **맥 ↔ 아이폰 동기화**: 같은 Apple ID로 로그인한 기기끼리 iCloud(CloudKit 비공개 데이터베이스)로 계획이 맞춰져요. 서버 없음 (`Shared/CloudPlan.swift`).
  - **항목 단위로 합쳐요** (`Shared/PlanMerge.swift`): 블록·할 일마다 바뀐 시각을 기록해서, 두 기기에서 따로 고쳐도 서로 덮어쓰지 않아요. 지운 항목은 지운 기록으로 남아 다시 살아나지 않아요.
  - 다른 기기에서 바꾸면 조용한 알림으로 몇 초 안에 반영되고, 앱이 켜져 있는 동안은 20초마다도 확인해요. 위젯도 체크하자마자 올리고, 새로 그릴 때 받아 와요.
  - 맥 앱은 이미 켜져 있으면 두 번째 실행을 막고 켜져 있는 창으로 넘겨요.
  - **처음 한 번 할 일**: developer.apple.com → Identifiers → iCloud Containers에 `iCloud.com.svxcza.hanjustack`을 만들고, 앱·위젯 App ID의 iCloud(CloudKit)에 연결. 개발용 빌드(`./build.sh`)로 한 번 실행해 기록 형식(Plan)을 만든 뒤, CloudKit Console → Schema → **Deploy Schema Changes**로 운영 환경에 배포해야 TestFlight·앱스토어판이 동기화돼요.
  - 앱스토어 서명판에서만 켜져요. GitHub 개인용 다운로드판은 동기화하지 않아요.

## 블록 만들기

- 걸리는 시간: − / + 로 10분씩 바꾸거나, 칸에 직접 입력 (`1:30`, `90분`, `2.5`, `3`, `1시간 30분`). 위·아래 화살표 키도 돼요.
- 복제: 블록에 마우스를 올리면 나오는 ⧉ 누르기 (같은 날 바로 뒤 빈칸에 생겨요) · ⌥(option) 누른 채 끌면 원하는 곳에 복사 · 블록 선택 후 ⌘D

## 위젯

바탕화면 우클릭 → 위젯 편집 → "한 주 쌓기"

- **한 주 판** (큰): 블록을 누르면 바로 회색 ✓ 완료 ↔ 되돌리기
- **할 일 목록**: 이번 주 할 일만 시간 없이 체크리스트로 나열 (고정 일정은 빼요). 네모를 누르면 바로 완료. 작은·가로 1×2·큰·가로 1×4 크기
- **오늘 블록**: 가로로 긴 크기는 오늘 시간을 9–12 | 13–16 | … 처럼 접어서 블록으로 보여줘요. 작은·큰 크기는 목록 (큰 크기에서 × 누르면 삭제)
- 위젯 버튼은 **앱을 열지 않고 위젯 안에서 바로** 처리돼요. 앱이 켜져 있으면 1~2초 안에 앱 화면에도 반영되고, 꺼져 있으면 다음에 열 때 반영돼요.
- 요일 이름을 누르면 그 주로 앱이 열려요. 이름 바꾸기·시간 옮기기는 앱에서 해요.

## 데이터 위치

앱과 위젯은 같은 App Group 컨테이너의 `state.json`을 공유합니다. 그룹 ID는 `Config/Signing.xcconfig`에서 설정합니다. 메뉴의 **계획 가져오기… / 계획 백업 내보내기…**로 기존 JSON을 가져오거나 백업할 수 있습니다. 이전 개인용 설치의 파일은 [이동 안내](APP_STORE.md#기존-개인용-설치에서-이동)를 참고하세요.

## 시간 설정

- 일정 배치·이동·시간 입력은 10분 단위입니다. 50분 수업을 그대로 등록할 수 있습니다. 10의 배수가 아닌 입력은 올림을 알립니다.
- 언어는 한국어/English를 선택합니다. 한국어 화면은 24시간제, 영어 화면은 AM/PM 표시를 사용합니다. 모든 언어에서 같은 24시간·일주일 일정과 10분 단위를 사용하며 시간대나 저장된 일정은 바꾸지 않습니다. 위젯에도 같은 언어를 적용합니다.
- 이전 30분 단위 저장은 v4로 변환하며 기존 날짜·시각·길이를 보존합니다.
- 출시 방향: US$2.99 일회성 앱 구매 제안. 실제 판매 가격은 App Store Connect에서 별도로 설정해야 합니다.
