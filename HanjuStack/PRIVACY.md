# 한 주 쌓기 개인정보 처리 안내

이 안내는 현재 저장소의 App Store 준비 버전을 설명합니다.

- 할 일의 이름, 일정, 완료 여부와 표시 설정은 사용자의 Mac에 저장됩니다.
- 앱과 위젯은 동일한 로컬 App Group 저장소를 사용합니다.
- 사용자 계정을 만들지 않으며, 계획을 개발자 서버로 보내지 않습니다.
- 광고·분석·추적 SDK를 포함하지 않습니다.
- 사용자가 백업을 내보내면 선택한 위치에 JSON 파일이 만들어집니다. 해당 위치가 다른 동기화 서비스의 폴더인지는 사용자가 관리합니다.
- 가져오기 전에 만들어진 로컬 백업도 앱의 공유 컨테이너에 남습니다. 계획과 백업의 삭제는 Mac의 앱 데이터 관리 기능을 통해 사용자가 관리할 수 있습니다.
- **레서와 대화**: 기본은 Apple 기기 안 모델이나 정해진 대사로, 대화가 기기 밖으로 나가지 않습니다. 사용자가 직접 Claude(Anthropic) 또는 OpenAI API 키를 넣고 그 AI를 고른 경우에만, 대화 내용과 대답에 필요한 계획 일부(오늘·이번 주 블록 이름, 날짜, 시간, 완료 여부)가 그 회사의 API로 바로 전송됩니다. 개발자 서버를 거치지 않고, 처리와 보관은 해당 회사의 정책을 따르며, 요금은 키 주인에게 청구됩니다. API 키는 기기의 키체인에만 저장됩니다.
- Apple App Store 결제는 Apple이 처리하며 이 앱은 카드 정보를 수집하지 않습니다.

출시 전 개발자는 이 안내를 공개 웹 주소에 게시하고, 지원 연락처를 추가해 App Store Connect에 등록해야 합니다. 이 문서가 존재하는 것만으로 심사/개인정보 요구사항을 충족했다고 간주하지 않습니다.
